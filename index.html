Convert files and merge into one PDF
Install PDF Creator

Install it like an app, then send files to it straight from WhatsApp, Drive or your scanner app.

Send files from other apps

In WhatsApp, Drive, Files, or a scanner app: tap Share → PDF Creator. Share one file or many, from as many apps as you like. They wait here until you create the PDF.

Not seeing PDF Creator in Share?
  1. Use Google Chrome (not Samsung Internet, Firefox or the in-app WhatsApp browser) to open this page.
  2. Tap ⋮ → Add to Home screen → choose Install, not "Create shortcut". A shortcut can't receive files.
  3. Check: Settings → Apps should list PDF Creator like a normal app. If it isn't there, it was added as a shortcut. Remove it and install again.
  4. Installed before today? Remove it and install again so Android learns about sharing.
  5. In the Share sheet, scroll the app row or tap More. New apps appear at the end.
  6. iPhone doesn't allow this for web apps. Use Add files instead.

Everything happens on this device. Files are never uploaded.
